# Export Price Calculator

Small Safari/iPhone-friendly export calculator.

Features:
- Customer price → factory price
- Factory price → customer price
- Quantity, ocean fees, local RMB fees, USD/CNY, export factor
- Tank rent in USD/day × number of days, with automatic total
- Full step-by-step calculation details
- Final commercial result with 3 decimals
- Responsive interface for iPhone
- Offline cache after first load

## GitHub Pages

In **Settings → Pages**:
1. Choose **Deploy from a branch**
2. Select **main**
3. Select **/ (root)**
4. Save

Then open the Pages URL in Safari. On iPhone use **Share → Add to Home Screen**.
